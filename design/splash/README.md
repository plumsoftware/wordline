# Экран запуска S01

Источник — `S01-launch.png`, непосредственно присланный пользователем 20 ноября 2026 года. Точная копия находится в `app/src/main/res/drawable-nodpi/launch_s01.png`.

`LaunchScreen.kt` выводит исходное изображение целиком: фон, логотип «СЛОВА», ленту «Путешествие», нарисованный индикатор и надпись «Загрузка...». Индикатор является частью статического изображения. Отдельный Material-индикатор поверх картинки не добавляется.

В исходном соотношении сторон 327 × 627 композиция совпадает с образцом; на других пропорциях `FillBounds` масштабирует её по ширине и высоте без обрезки. Исходник имеет только 327 × 627 пикселей: увеличение до разрешения телефона не добавляет деталей. Preview имеет размеры исходного образца.

Экран показывается минимум 900 мс и остаётся до готовности игровых данных. Ошибка загрузки выводится диалогом с повторной попыткой. При загрузке системные панели скрыты, после неё восстанавливаются. На Android 8–11 изображение также используется в стартовом окне. На Android 12+ системное стартовое окно допускает только одноцветный фон, поэтому полная композиция появляется с первым кадром Activity; стандартная иконка и выходная анимация отключены.

Сборка, запуск на устройстве и сравнение скриншота приложения с образцом пока не выполнялись.

# Главный экран по образцу S02

`HomeScreen.kt` заменяет прежние типовые карточки отдельными Compose-компонентами. Расположение рассчитано по образцу 327 × 627: основная область 327 × 555 и нижняя панель высотой 72. Preview использует баланс 240 и уровень 24 только как демонстрационные данные; приложение отображает реальный прогресс.

Подключены баланс и кошелёк, настройки, карта по нажатию на уровень, запуск игры, задания, подарок и три раздела нижней навигации. Ежедневный кроссворд доступен через задания, справка — через настройки. Главный экран работает без системных панелей; остальные страницы сохраняют безопасные отступы.

Фон `game_lake_day.webp`, монета `item_coin.png`, подарок `item_gift.png` и иконки настроек/заданий используются из существующих ресурсов проекта. Для композиции S02 добавлены векторы гор, листа и цветного планшета задания. Поверхности, прогресс и кнопка рисуются средствами Compose. Весь экран не подменяется статичным скриншотом.

Точный фон S02 и подарок с фиолетовой лентой отличаются от отдельных ресурсов в пакете. Используемый фон кадрируется сверху, чтобы приблизить положение гор и озера; подарок сохраняет золотую ленту исходного ресурса. Полное пиксельное совпадение с S02 не подтверждено. Сборка и запуск отложены пользователем для проверки в Android Studio.

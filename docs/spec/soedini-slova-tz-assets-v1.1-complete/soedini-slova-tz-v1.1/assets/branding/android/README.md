# Android launcher 1.1

Скопировать `res/` в Android-модуль и привязать @mipmap/ic_launcher и @mipmap/ic_launcher_round в manifest. Для minSdk26 доступны adaptive icon layers; v33 добавляет monochrome. Цвет фона принадлежит этой игре. Эти XML проверяются синтаксически, компиляция Android-проектом ещё требуется. Safe-zone и маски дополнительно проверять на устройстве. Плоские PNG512 и SVG остаются источниками дизайна, а не автоматической заменой adaptive icon.

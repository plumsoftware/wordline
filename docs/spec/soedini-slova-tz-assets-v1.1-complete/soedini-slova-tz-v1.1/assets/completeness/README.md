# Полнота графики и состояний 1.1

`screen-inventory.json` и `screen-element-coverage.csv` связывают каждый элемент 52 экранов/состояний с файлом или рекурсивным контрактом нативного компонента.
`component-contracts.json` задаёт размеры-референсы, варианты, состояния, цвета, семантику и вложенные компоненты.
`button-labels-ru.xml` содержит строки кнопок для адаптации в Android-проекте, `button-labels.json` — читаемый реестр.
`../components/` содержит поверхности каждого требуемого состояния в обычной и контрастной темах. SVG и PNG — дизайн-материалы; живые кнопки реализуются Compose, надпись/сумма не зашиты в PNG.
`../ui-icons/variants/` содержит цветовые варианты каждой геометрии; в Compose обычно используется один VectorDrawable и tint.
`../state-catalog.html` показывает все состояния с подписями, иконками и loading-индикаторами.

Полнота относится к зафиксированному UI-объёму, а не к будущим ещё не описанным функциям. Системные file picker/share chooser и реальные рекламные controls рисуются Android/SDK. Типографика и системные glyph не поставляются картинками. Количество файлов не является само по себе доказательством полноты — проверяется таблица покрытия.

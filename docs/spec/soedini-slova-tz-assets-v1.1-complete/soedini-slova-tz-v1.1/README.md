# Соедини слова - кроссворды

## Техническое задание · редакция 1.1 · 20 ноября 2026

Полное ТЗ для разработки Android-игры на Jetpack Compose, Gradle 9.4.1 и AGP 9.2.0. Собственный сервер отсутствует. Монетизация — рекламная сеть Яндекса. Встроенных покупок нет.

## Как читать

Откройте `index.html` в браузере после распаковки всего архива. Он содержит полный текст, оглавление и шесть листов макетов. Интернет для чтения не требуется. `Техническое-задание.md` — тот же текст в редактируемом Markdown; `chapters/` — отдельные главы. Для поиска используйте Ctrl+F / Cmd+F. HTML можно распечатать средствами браузера.

1. Заказчик проверяет главы о продукте, экранах, экономике и реестре решений.
2. Android-разработчик читает документ целиком, затем сверяет архитектуру, контракты данных и сценарии приёмки.
3. Дизайнер использует главу UI и `design/`. Старое название на изображениях заменяется новым при реализации.
4. Тестировщик использует сценарии QA и требования с идентификаторами.

## Статус требований

**Зафиксировано пользователем:** название «Соедини слова - кроссворды»; Android Compose; Gradle 9.4.1; AGP 9.2.0; игра по двум референсам RuStore; яркий современный дизайн; отсутствие собственного сервера и покупок; РСЯ.

**Проектное решение ТЗ:** все остальные числовые значения, структура контента, архитектура, рекламные ограничения и правила ниже — конкретная предлагаемая спецификация версии 1.0, а не отдельно согласованные обещания заказчика. По ней можно оценивать и планировать работу. Изменения оформляются новой редакцией; не подменять этими решениями исходные ограничения.

## Что уже сделано и чего нет

Создано ТЗ из 12 глав, приложены 36 визуальных концептов на шести PNG-листах и по отдельности. Подготовлены 10 новых фонов, 10 открыток, 24 объёмных предмета с прозрачностью, 70 UI-иконок (SVG и Android XML), брендинг и поверхности UI. Откройте `assets/gallery.html` для просмотра ресурсов. Это не исходный Android-проект, не готовый игровой словарь, не проверенный набор уровней и не макет Figma. Сборка приложения не выполнялась. Проверки архива перечислены в `PACKAGE-CHECKS.txt`.

Приоритет: явное требование пользователя → правила и контракты этого ТЗ → текстовое описание экрана → иллюстративный макет. Цены, календарные даты, сетки и старое название на PNG не имеют приоритета над ТЗ.

## Состав

- `index.html`, `styles.css` — автономная версия для чтения.
- `Техническое-задание.md` — полный текст.
- `chapters/` — главы ТЗ.
- `design/` — шесть исходных листов, 36 отдельных экранов и промпты предыдущего этапа.
- `assets/` — графические ресурсы, каталог, реестр JSON/CSV и промпты новой генерации.
- `examples/` — валидные небольшие примеры форматов уровня и баланса; не релизный контент.
- `SHA256SUMS.txt` — контрольные суммы файлов комплекта.
- `PACKAGE-CHECKS.txt` — фактически выполненные проверки пакета.

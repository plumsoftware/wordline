# Материалы для RuStore

Подготовлено 22 ноября 2026. Шесть вертикальных промо — в `promo/upload`, редактируемая компоновка — `render-promos.ps1`, PNG-мастера — `promo/masters`. Для просмотра всей серии откройте `preview.html` или `promo/preview.jpg`. Краткое и полное описания сохранены в отдельных TXT.

## Общий макет

Каждое JPG — 1080×1920 (9:16), RGB, без прозрачности, меньше 3 МБ. Во второй версии заголовок помещён на кремовую фигурную плашку с листьями в стиле игровых разделов. Он занимает две строки, ключевое слово выделено зелёным. Телефон увеличен примерно на 3,3%, шрифт — с 76 до 84 px. Телефон, экран, плашка и текст рисуются одним шаблоном в одинаковых координатах; различаются только заголовок и содержимое экрана. Первое промо показывает игровой процесс. Предыдущая серия сохранена в `rustore-promo-pack-v1.zip`.

Точные размеры и список файлов записаны в `promo-manifest.json`. Плашка увеличена: x22/y0, 1036×356; края с листьями отрисовываются узкими боковыми сегментами по 92 px, чтобы весь текст оставался внутри кремового центра. Область заголовка: x84/y94, 912×194; шрифт Segoe UI Bold, 84 px; акцент #078452. Телефон: x166/y342, 748×1550. Область экрана: x190/y370, 700×1494.

Иллюстрированный фон и демонстрации экранов созданы по материалам проекта. Это промо-макеты, а не снимки запущенного APK. Перед публикацией их нужно сопоставить с окончательным релизным интерфейсом; изображения не являются свидетельством проверки сборки. В частности, показанное игровое состояние иллюстрирует механику, а не гарантирует точный набор слов конкретного номера уровня.

## Требования RuStore

По официальной инструкции для мобильной карточки нужны как минимум три изображения; за один раз можно добавить до десяти. Для телефона подходят PNG/JPG до 3 МБ, предельное разрешение — 2160×3840. Выбрана вертикальная ориентация, соответствующая игре. [Инструкция по публикации](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication).

На промо должен быть актуальный интерфейс и поддерживаемые функции; нельзя добавлять системные панели Android, рекламу других сервисов или вводящие в заблуждение обещания. Тексты — на русском. [Правила модерации, раздел 6.6](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).

Предел краткого описания — 80 символов, полного — 4000. Описание сообщает о рекламе, не обещает отсутствие рекламы или медицинский/образовательный результат. Контакты разработчика и возрастную маркировку необходимо заполнить в Консоли отдельно. Название в манифесте проекта — «Соедини слова - кроссворды»; игровые экраны используют логотип путешествия.

[Официальное пояснение Android](https://developer.android.com/blog/posts/prepare-your-app-for-the-resizability-and-orientation-changes-in-android-17).

Compose уже использует явную светлую палитру и выбранное внутри игры оформление, без зависимости от системной тёмной темы. В теме окна дополнительно отключён Android Force Dark. Пользовательские игровые настройки оформления остаются доступными.

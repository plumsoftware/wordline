# Соедини слова — кроссворды

Android/Jetpack Compose-игра по `soedini-slova-tz-assets-v1.1-complete.zip`. Продолжение реализации после первого среза: в исходники добавлены кампания, ежедневные режимы, метапрогресс, файлы, звук и реклама.

## Реализованные возможности

- 1000 основных и365ежедневных конечных кроссвордов,438авторских словарных записей. Первые30уровней сохраняют исходные ответы и координаты. Уровни не генерируются на телефоне. Пакет1.6МиБ, contentVersion2; редакторская приёмка слов, сложности и темпа ещё впереди.
- Целевые/бонусные слова, пересечения, три вида подсказок, звёзды, бесплатные подсказки в повторе без повторной награды. Отдельное обучение с бесплатной буквой. Свайп с возвратом, проверка сегмента быстрого движения, ввод нажатием и клавиатурой.
- Room: профиль, сессии, лучшие результаты, журнал и совокупное состояние прогресса. Все денежные операции транзакционны, ключи наград уникальны. Миграция БД1→2 сохраняет прежние таблицы; destructive fallback отсутствует.
- Логическая дата без отката назад; календарь месяца, отдельная ежедневная сессия, подарки1…7, серия, три задания с автоматической выдачей готовых призов при смене даты,12достижений и личная тропа.
-10локаций/фонов/открыток, открытие глав, коллекция, оформление, статистика и история7дат. Открытки можно отправлять через FileProvider или сохранять через системный picker.
- Экспорт `.wordsave`, строгий импорт с предпросмотром, SHA-256 и каноническим JSON, проверка целостности модели, атомарная замена и новое поколение профиля. Перед заменой создаётся проверенная страховочная копия. Хранятся3последние внутренние копии; внешние файлы игра не удаляет. Настройки устройства при импорте сохраняются.
- Yandex Mobile Ads8.7.0: демонстрационные rewarded/interstitial в debug, ручная инициализация после разрешения загрузки рекламы, квоты, интервал активной игры, отмена/5секунд ожидания, отдельная фиксация награды, поздние callbacks и защита поколения профиля. В QA реклама выключена. Нет баннера и рекламы при выходе. Debug-диагностика содержит20последних событий.
-5оригинальных синтезированных эффектов и16-секундная музыкальная петля, отдельные переключатели музыки/эффектов/вибрации, обработка audio focus. Настройки контраста, крупных букв, уменьшенного движения и альтернативного ввода.

## Три магазина

В [app/build.gradle.kts](app/build.gradle.kts) созданы `rustore`, `googlePlay`, `huaweiAppGallery`, dimension `store`. В начале файла находится `storeAdUnits`: для каждого магазина отдельно пара `(rewarded, interstitial)`. Эти строки можно заполнить позже; значения Gradle properties имеют приоритет:

```properties
wordline.rustore.rewardedAdUnitId=
wordline.rustore.interstitialAdUnitId=
wordline.googlePlay.rewardedAdUnitId=
wordline.googlePlay.interstitialAdUnitId=
wordline.huaweiAppGallery.rewardedAdUnitId=
wordline.huaweiAppGallery.interstitialAdUnitId=
```

Для каждого того же префикса предусмотрены `.supportEmail`, `.privacyUrl`, `.audience` (`general` или `children`). Реальных значений пока нет по указанию владельца. Debug всегда использует `demo-rewarded-yandex`/`demo-interstitial-yandex`; release не подставляет их вместо настоящих ID. `validateReleaseInputs` блокирует release без сведений издателя. Ключ подписи в проект не добавлялся. Подготовка подписанного релиза и публикация требуют данных владельца и отдельной приёмки.

Build types: `debug` с suffix `.debug`, `qa` с suffix `.qa` и отключённой рекламой, `release` с полным R8/resource shrinking. Основной applicationId остаётся `ru.plumsoftware.wordline`; у store-flavor он одинаковый. Если магазины потребуют отдельные applicationId, это нужно согласовать до регистрации блоков и подписания.

## Статус проверок

**Текущие игровые исходники ещё не компилировались, не тестировались и не запускались.** Владелец повторно выбрал «Пока оставить без сборки». До реализации игры успешно собирался только Hello Android с заданными Gradle/AGP. Старый `app/build/outputs/apk/debug/app-debug.apk` не соответствует текущему коду.

Подготовлены23содержательныхunit-теста и9Android-тестов; прежние2теста шаблона сохранены. Они не выполнялись. Schema export Room настроен в `app/schemas`, но KSP ещё не генерировал схему. Добавленные зависимости, SDKAPI и R8 требуют реального разрешения/компиляции. Нет результатов TalkBack, UI-скриншотов, process death, реального picker/SDK и измерений производительности.

После разрешения владельца:

```sh
python3 tools/validate_content.py
./gradlew :app:testRustoreDebugUnitTest :app:assembleRustoreDebug :app:assembleGooglePlayDebug :app:assembleHuaweiAppGalleryDebug
./gradlew :app:lintRustoreDebug
# При доступном устройстве:
./gradlew :app:connectedRustoreDebugAndroidTest
# Фиксация фактически разрешённого графа:
./gradlew :app:dependencies --write-locks
```

Release-проверки запускаются после ввода реальных настроек. Никогда не проверять автоматическими кликами production-рекламу. Для разработки также доступен `:app:assembleRustoreQa`.

## Контент и файлы

`tools/prepare_campaign.py` — воспроизводимый авторский конвейер1000+365, seed20261120; использует исходные определения и `tools/dictionary-ru.tsv`. `tools/content-editorial-report.json` описывает подготовленный объём и pending-редактуру. Инструмент запускался для создания контента, отдельный валидатор пока не запускался. Старый `prepare_content.py` оставлен как источник первых30фикстур; его прямой запуск заменяет пакет ранней версией, поэтому для текущего пакета используется именно `prepare_campaign.py`.

`tools/validate_content.py` подключён к `preBuild`; ему нужен Python3 на машине разработчика. Проверяются checksum, обе таблицы IDs, буквы, направления, связность, размеры, нежелательные примыкания, определения и бонусы. Runtime проверяет тот же класс инвариантов. `tools/prepare_audio.py` готовит собственные WAV без сторонних семплов. Реестр происхождения графики — `app/src/main/assets/content/asset-sources.json`.

Формат сохранения использует RFC8785/JCS на ограниченном домене: объекты, массивы, строки, bool/null и целые числа в безопасном диапазоне IEEE754. Дробные/экспоненциальные записи чисел отвергаются схемой. Строки не нормализуются. Дубликаты ключей, неправильный UTF-8, непарные суррогаты, глубина>20, файл>10МиБ и>100000логических записей запрещены. Контрольная сумма обнаруживает порчу, но не защищает от намеренного редактирования/отката офлайн-снимка.
